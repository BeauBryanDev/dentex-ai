# Torch must come from the CPU index, or pip pulls the CUDA build
# (~2-3 GB of nvidia_* packages) onto a machine with no NVIDIA GPU:
#
#     pip install torch --index-url https://download.pytorch.org/whl/cpu
#     pip install -r requirements.txt
#
# The pinned torch below carries the +cpu local version identifier, so a plain
# `pip install -r requirements.txt` will not resolve it from PyPI.
#
# Every pin below is the version currently installed and working on this
# machine, not the newest on PyPI. Bump deliberately, not by default.
